v1.3.0 · 지원 문서: TXT · PDF · DOCX · HWP(v5) · HWPX (병합 표 · 부칙 별도 비교 지원)

웹앱 배포 · 최신 버전(v1.3.0) 업데이트 안내

바탕화면 CTLR 폴더의 파일로 GitHub 및 Netlify에 즉시 반영할 수 있습니다.

현재 앱 폴더 위치 및 파일 구성 (c:\Users\user\Desktop\CTLR)

폴더 내 index.html(단독 실행 통합본), style.css, app.js, README.md 4개 파일로 구성되어 있습니다.

방법 1 (추천) GitHub 저장소에 덮어쓰기 → Netlify 자동 배포

  1. 연결된 GitHub 저장소(github.com/g9775045-musyu/Statement-of-Changes)에 접속합니다.
  2. 화면 오른쪽 위 Add file → Upload files 버튼을 클릭합니다.
  3. 바탕화면 CTLR 폴더 안의 파일 4개(index.html, style.css, app.js, README.md)를 드래그하여 올린 뒤 하단 초록색 Commit changes 버튼을 누릅니다.
  4. GitHub와 연결된 Netlify 사이트가 약 15~30초 뒤에 자동으로 최신 버전으로 업데이트됩니다!

방법 2 (수동 배포 시) Netlify 대시보드에서 폴더째 드래그하여 즉시 업데이트

  1. app.netlify.com 에 로그인한 뒤 기존에 만든 사이트를 선택합니다.
  2. 상단 또는 왼쪽 메뉴에서 Deploys 탭을 클릭합니다.
  3. GitHub 연동 사이트라면 Trigger deploy → Deploy site를 누르고, 수동 업로드 사이트라면 화면 아래쪽 점선 상자(Drag and drop your site output folder here)에 바탕화면의 CTLR 폴더를 통째로 끌어다 놓으면 5초 만에 반영됩니다.

방법 3 (파일 직접 공유) 학교·기관 메신저(쿨메신저 등)로 index.html 파일 전달

별도의 프로그램(Python 등) 설치 없이 index.html 파일 하나만 동료 교직원에게 보내주시면, 받는 분 컴퓨터에서 더블클릭만으로 크롬·엣지 브라우저에서 즉시 실행됩니다. 입력한 조문과 업로드한 문서는 외부 서버로 전송되지 않고 사용자 컴퓨터(브라우저) 안에서만 안전하게 처리됩니다.
