이 웹앱을 배포·공유하는 방법 안내

별도 백엔드 없이 정적 웹사이트로 배포할 수 있습니다. PDF·HWP 등 일부 기능은 인터넷 연결이 필요합니다.

방법 1 (가장 간편) Netlify Drop — 배포 폴더를 올려 웹 주소 만들기

  1. 배포용 폴더에 index.html을 둡니다. 현재 작업물은 outputs 폴더에 있습니다. start-app.cmd는 웹 배포에는 필요하지 않습니다.
  2. 브라우저에서 app.netlify.com/drop 에 접속합니다.
  3. index.html이 들어 있는 배포용 폴더를 점선 영역에 드래그합니다. 배포가 끝나면 https://...netlify.app 주소가 제공됩니다.

방법 2 GitHub Pages — GitHub 저장소에서 배포

  1. GitHub(github.com)에서 새 저장소(Repository)를 생성하고 이름을 정합니다.
  2. index.html 파일을 업로드(Add file → Upload files) 후 Commit 합니다.
  3. 저장소의 Settings → Pages에서 배포 원본을 main 브랜치와 루트 폴더로 지정하고 저장합니다. 배포가 완료되면 https://아이디.github.io/저장소명/ 주소가 표시됩니다. GitHub Free에서는 공개 저장소로 배포해야 합니다.

방법 3 (보안·내부망 공유) 학교·기관 메신저(쿨메신저 등)로 파일 직접 공유

문서 본문은 브라우저에서 처리하며 앱 서버로 전송하는 기능은 없습니다. 다만 PDF·HWP 처리용 코드는 외부 CDN에서 불러와 실행됩니다. 앱에는 로그인 제한이 없으므로, 민감한 문서를 다룰 때는 승인된 내부 배포와 라이브러리 자체 호스팅을 먼저 검토하세요. 로컬에서 쓸 때는 index.html과 start-app.cmd를 함께 전달하고, 받는 사람 컴퓨터에 Python과 인터넷 연결이 필요합니다.
