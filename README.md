# 신·구조문대비표 자동 생성기

법령·조례·학칙·기관 규정의 현행 조문과 개정안을 비교해 신·구조문대비표 작성을 돕는 브라우저용 웹앱입니다. 비교 결과를 확인하고, 표를 복사해 한글(HWP) 또는 Microsoft Word 문서에 붙여넣을 수 있습니다.

> 이 도구는 대비표 작성을 보조합니다. 조문 대응 관계와 밑줄·삭제·신설 표시를 원문과 대조해 최종 검토해 주세요.

## 주요 기능

- 현행(구 조문)과 개정안(신 조문)을 붙여넣거나 파일로 불러와 비교
- 조문 번호를 기준으로 조문을 대응하고, 조·항·호의 신설·삭제 및 변경 표시
- 조문 전체 비교와 문단·줄 단위 비교 방식 제공
- 개정된 문구는 개정안 쪽에 밑줄 표시
- 신설 내용은 현행 쪽에 `<신설>`, 삭제된 내용은 개정안 쪽에 `(삭제)` 또는 설정한 표시로 나타냄
- 변경 없는 조문은 `(현행과 같음)` 또는 `----`로 줄여 표시하도록 설정 가능
- 일부개정, 제정·전부개정 등 상황에 맞춰 표시 방식을 조정
- 결과를 2단 표로 확인하고 한글·워드용으로 복사하거나 문서로 저장, 인쇄/PDF 출력
- 변경·신설·삭제 개수 확인 및 화면 검수용 강조 보기

## 지원 파일

현행 조문과 개정안 각각 다음 형식의 파일을 불러올 수 있습니다.

- TXT (`.txt`)
- PDF (`.pdf`)
- Microsoft Word 문서 (`.docx`)
- 한글 문서 HWP 5 바이너리 형식 (`.hwp`)
- 한글 문서 HWPX 형식 (`.hwpx`)

암호가 설정된 HWP 문서는 암호를 해제한 뒤 사용하세요. 스캔한 PDF처럼 본문이 이미지로만 들어 있는 파일은 텍스트 추출이 되지 않을 수 있습니다. 이 경우 OCR로 텍스트를 인식하거나 문서에서 본문을 복사해 입력란에 붙여넣으세요. 파일 구조와 문서 안의 표·글상자·특수 서식 등에 따라 파싱 결과가 달라질 수 있으므로 변환된 조문을 검토해야 합니다.

## 사용 방법

1. 웹앱을 엽니다.
2. **현행(구 조문)** 입력란에 현행 규정 내용을 붙여넣거나 파일을 올립니다.
3. **개정안(신 조문)** 입력란에 개정안을 붙여넣거나 파일을 올립니다.
4. 개정 유형과 변경 없는 조문·삭제·신설 표시 방식을 선택합니다.
5. **대비표 생성**을 눌러 결과를 확인합니다.
6. 조문 순서, 변경 표시, 누락 여부를 원문과 비교해 검토합니다.
7. **표 복사**로 한글 또는 Word에 붙여넣거나 저장·인쇄 기능을 이용합니다.

제정·전부개정처럼 현행 조문이 없는 경우에는 현행 입력란을 비워 두고 개정안을 입력할 수 있습니다. 조문 번호가 바뀌거나 조문이 삽입·이동된 경우에는 자동 비교 결과를 특히 주의해서 확인하세요. 자동 비교가 법률적 판단을 대신하지 않습니다.

## GitHub Pages로 배포하기

이 프로젝트는 별도의 서버 프로그램 없이 실행하는 정적 웹페이지입니다.

1. GitHub에 저장소를 새로 만듭니다.
2. `index.html`과 이 `README.md` 파일을 저장소 최상위에 업로드합니다.
3. 저장소에서 **Settings → Pages**를 엽니다.
4. **Build and deployment**의 **Source**를 `Deploy from a branch`로 선택합니다.
5. 브랜치는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
6. Pages 설정 화면에 나타난 사이트 주소를 엽니다. 주소는 보통 `https://사용자이름.github.io/저장소이름/` 형태입니다.

파일을 업데이트할 때는 새 `index.html`을 같은 위치에 올리고 변경 내용을 커밋하면 다시 배포됩니다. `start-app.cmd`는 Windows에서 로컬 실행 시 사용하는 보조 파일이며 GitHub Pages에는 필요하지 않습니다.

## 로컬에서 실행하기

`index.html`을 브라우저에서 직접 열어도 되지만, 기능과 브라우저 환경에 따라 로컬 웹서버를 이용하는 편이 안정적입니다. Windows에서는 `start-app.cmd`를 실행하면 로컬 서버가 시작되고 브라우저가 열립니다. 이 방법을 사용하려면 Python이 설치되어 있어야 합니다.

## 개인정보와 보안

- 문서 본문을 앱 서버로 전송하는 기능은 없습니다. 파일은 사용자의 브라우저에서 읽고 처리합니다.
- 앱은 Tailwind CSS, 글꼴, 아이콘 및 PDF·DOCX·HWP/HWPX 처리용 라이브러리를 외부 CDN에서 불러옵니다. 따라서 앱을 열 때 인터넷 연결이 필요합니다.
- 외부 라이브러리 코드는 브라우저 페이지 안에서 실행되므로, 민감한 문서를 다루기 전에는 기관의 정보보안 기준에 따라 사용 가능 여부를 확인하세요. 필요한 경우 라이브러리를 프로젝트에 포함해 자체 호스팅하는 배포 방식을 검토할 수 있습니다.
- GitHub 저장소가 공개이면 소스 코드가 공개됩니다. GitHub Pages 사이트도 인터넷에서 공개적으로 열 수 있으며 로그인 제한 기능은 포함되어 있지 않습니다. 비공개·내부 문서가 들어간 파일을 저장소에 올리지 마세요.

## 기술 구성

HTML, CSS, JavaScript 기반의 단일 페이지 앱입니다. PDF.js, Mammoth.js, JSZip, CFB, Pako 등의 브라우저 라이브러리를 CDN에서 불러옵니다. 서버나 데이터베이스를 별도로 운영하지 않습니다.
