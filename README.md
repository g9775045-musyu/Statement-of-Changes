# ⚖️ 법조문·학칙 신·구조문대비표 자동 생성기 (Legal Diff Table Generator)
대한민국 **법제처 「법령 입안·심사 기준」** 및 **자치법규·학교규칙(학칙) 개정 실무 표준**을 준수하여, 현행(구 조문)과 개정안(신 조문)을 입력하면 **신·구조문대비표**와 **부칙 신·구조문대비표**를 자동으로 생성해 주는 웹 애플리케이션입니다.
별도의 서버나 프로그램 설치 없이 브라우저(Client-Side)에서 즉시 작동하며, 외부 서버로 문서 데이터가 전송되지 않아 **보안성이 뛰어납니다.**

## 📋 버전 변경 내역 (Changelog)
### 🚀 v1.3.0 (최신 업데이트 - 2026. 11. 10.)
1. **표(Table) 내부 병합 셀(`가로 병합 colspan` · `세로 병합 rowspan`) 완벽 지원**
   - **2차원 가상 격자(2D Grid) 정규화 엔진 도입**: 조문 내 표에 세로 병합(`rowspan`)이나 가로 병합(`colspan`)된 셀이 있을 때 열이 밀려 엉뚱한 칸끼리 비교되던 문제를 근본적으로 해결했습니다.
   - **자동 병합 기호 변환**: 한글(HWP)·MS 워드·엑셀에서 병합된 표를 복사해 붙여넣거나(`Ctrl+V`), `.docx`·`.hwpx` 파일을 업로드하면 가로 병합은 `<<`, 세로 병합은 `^^` 기호로 자동 변환되어 열 정렬을 유지합니다.
   - **실제 병합 셀 복원 렌더링**: 비교 결과 표를 화면에 그리거나 한글(HWP)·MS 워드로 복사/저장할 때, `^^` 및 `<<` 기호(또는 `{가로N}`, `{세로N}`)를 분석하여 실제 `<td rowspan="N" colspan="M">` 병합 셀 구조로 복원합니다.
2. **부칙(附則) 자동 감지·분리 및 별도 『부칙 신·구조문대비표』 작성**
   - 현행(구 조문) 및 개정안(신 조문) 입력창 하단에 `부칙`(또는 `부 칙 <제2026-X호...>`)이 포함되어 있으면 본문 조문과 섞이지 않도록 **자동으로 분리**합니다.
   - 본문 신·구조문대비표 하단에 별도의 A4 시트로 **『부칙 신·구조문대비표』**를 독립 생성합니다.
   - **`[부칙 표만 따로 복사]`** 전용 버튼을 제공하며, 상단 `[한글(HWP)·워드용 표 복사]` 및 `.doc`/`.html` 저장 시 본문 표와 부칙 표가 함께 내보내집니다.
3. **UI/UX 레이아웃 및 글자 배치 개선**
   - 상단 Step 1 제목(`현행(구 조문) 및 개정안(신 조문) 입력 · 파일 업로드`)과 안내 배지가 좁은 화면에서도 글자가 쪼개지거나 밀리지 않도록 `word-break: keep-all` 및 `whitespace-nowrap` 정렬을 적용했습니다.
   - 불필요한 별도 부칙 입력창을 제거하여, 기존 좌우 2개의 입력창만으로 본문과 부칙을 한 번에 처리할 수 있도록 인터페이스를 단순화했습니다.

## 💡 주요 기능 사용 팁
### 1. 표(Table) 및 병합 셀 입력 방법
- **가장 쉬운 방법**: 한글(HWP), 워드, 엑셀에서 표를 드래그하여 복사(`Ctrl+C`)한 뒤, 입력창에 그대로 붙여넣기(`Ctrl+V`) 하시면 병합된 셀까지 자동으로 변환됩니다.
- **직접 수정할 때 사용하는 병합 기호**:
  - **`^^`** : 바로 **윗칸과 세로로 합쳐진 칸(`rowspan`)**을 의미합니다.
  - **`<<`** : 바로 **왼쪽 칸과 가로로 합쳐진 칸(`colspan`)**을 의미합니다.
```text
| 구분 | 대상 및 사유 | 인정 일수 | 제출 서류 |
| 경조사 | 부모·조부모 사망 | 5일 | 가족관계증명서 |
| ^^ | 형제·자매 사망 | 3일 | 가족관계증명서 또는 주민등록등본 |
```
> 위와 같이 입력하면 첫 번째 열의 **`경조사`** 칸이 위아래 2줄로 깔끔하게 세로 병합되어 비교됩니다.
### 2. 부칙(附則) 별도 비교표 자동 생성 방법
- 별도의 입력창에 넣을 필요 없이, `현행 (구 조문)` 또는 `개정안 (신 조문)` 입력창 맨 아래에 아래와 같이 `부칙`으로 시작하는 줄을 함께 적어주시면 자동으로 감지하여 하단에 **『부칙 신·구조문대비표』**를 따로 만들어 줍니다.
```text
부칙 <제2026-5호, 2026. 9. 1.>
제1조(시행일) 이 규정은 공포한 날부터 시행한다.
제2조(경과조치) 이 규정 시행 당시 종전의 규정에 따른 처분은 이 규정에 따른 것으로 본다.
```

## 🌐 GitHub 및 Netlify 업데이트(배포) 방법
1. **GitHub 저장소 업데이트**:
   - GitHub 저장소 페이지 우측 상단 **`Add file`** → **`Upload files`** 클릭
   - `index.html`, `style.css`, `app.js`, `README.md` 파일을 드래그 앤 드롭한 뒤 하단 **`Commit changes`** 클릭
2. **Netlify 반영**:
   - GitHub와 연동된 Netlify 사이트는 Commit 후 **약 15~30초 내에 자동으로 최신 버전이 배포**됩니다.
   - 수동 배포(Drop) 방식을 사용 중인 경우 Netlify의 **`Deploys`** 탭 하단 점선 영역에 `CTLR` 폴더를 드래그 앤 드롭하면 즉시 반영됩니다.
